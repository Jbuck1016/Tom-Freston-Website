# Tom Freston — Unplugged

Promotional website for **Unplugged: Adventures from MTV to Timbuktu**, the memoir by Tom Freston, cofounder of MTV and former CEO of Viacom.

## Tech Stack

- Single-file static HTML (`index.html`)
- [Tailwind CSS](https://tailwindcss.com/) via CDN — no build step
- Google Fonts (Playfair Display + Inter)
- Vanilla JavaScript (smooth scroll, mobile menu, retailer modal)

## Deploy

```bash
vercel --prod
```

## Clone (Mac)

```bash
git clone git@github.com:Jbuck1016/Tom-Freston-Website.git
```
